# Harrison Production Image Set

Last updated: 2026-08-03

The public website should use `assets/photos/final-webp/` for customer-facing images. These files are cropped, lightly corrected, compressed WebP assets made from approved store photos/reel frames. Do not edit brand labels or packaging. If a label or package looks wrong, crop it out or do not use that shot.

Do not move AI-generated or sourced product images into this production set until the user approves the exact image and page placement. Current AI adult-product candidates are review-only under `assets/ai-product-candidates/`.

## Production Rules

- Use final WebP files on public pages.
- Keep `asset-approval.html`, `assets/reel-review/`, `assets/photos/approved-sources/`, `assets/photos/approved-webp/`, `assets/photos/crop-candidates/`, and temporary JPG masters out of production deploys.
- Adult tobacco/vape pages should prefer the real user-supplied store photos over generated candidates.
- Do not use the original full `ready-to-drink-lineup-965F1C49-t7` frame on public pages; use `canned-drinks-crop-safe-615.webp`.
- Avoid reel shots with visible social text overlays, sparkles, fake-looking staged backgrounds, or incorrect packaging.
- Cigarette planning should stay limited to confirmed Marlboro and Newport unless the user approves additional brands.
- Vape planning should stay limited to confirmed Breeze and Geek Max unless the user approves additional brands.
